Edit PDF

Edit teks seperti di Word, atur gambar seperti di PowerPoint, gabung, pisah, dan kompres — semua di satu tempat. PDF hasil scan dan foto dokumen juga bisa diedit.

Atau seret file ke sini. Bisa beberapa file sekaligus (digabung jadi satu).

Diproses di browser Anda. Halaman yang Anda ubah dibangun ulang; halaman lain tetap seperti aslinya.

100%

Halaman: klik kanan (atau ⋯) untuk halaman kosong, duplikat, putar, hapus, simpan sebagian, atau baca teks (OCR); seret untuk mengubah urutan; jatuhkan PDF/gambar ke panel kiri untuk menyisipkan. Ctrl/Shift+klik memilih beberapa halaman.

Logo atau grafik belum bisa dipindah? Pakai ✂ Area → gambar lalu seret kotak di sekitarnya. Klik teks untuk langsung mengetik. Teks dipindah dengan Alt+seret (atau pilih dulu lalu seret), sudut untuk mengubah ukuran. Gambar & bentuk: seret untuk memindah, titik bulat di atas untuk memutar. Halaman yang diubah ditandai titik oranye.
